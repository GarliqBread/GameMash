# Security

If you find a security problem in GameMash, please report it privately rather than in a public issue: use [Report a vulnerability](https://github.com/GarliqBread/GameMash/security/advisories/new) on the repository's Security tab.

Include what you found, how to reproduce it, and what someone could do with it. You'll get a reply within a few days. Once a fix is out, the report is published with credit to you, unless you'd rather stay anonymous.

This covers the code in this repository and the hosted version at gamemash.io and play.gamemash.io. Please don't run automated scans or load tests against the hosted version, and don't access other people's sessions.
